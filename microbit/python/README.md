# MicroPython

Textcode — **nicht** für den Workshop selbst. Im Workshop wird ausschließlich
mit Blöcken gearbeitet (siehe `../../CLAUDE.md`).

Wofür dann:

- **Hardware-Check** vor der Messe: Motoren, Liniensensor, Laserscanner einmal
  durchklingeln, ohne MakeCode zu öffnen
- **Zugabe** für Schüler, die schon programmieren können und nach Station 6
  noch Zeit haben

Geflasht wird mit dem Mu-Editor oder `uflash`; beides braucht kein Internet,
muss aber vorher auf den Arbeitsplätzen liegen.
