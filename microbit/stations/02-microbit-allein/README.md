# Station 02 — Der micro:bit allein

LED-Matrix, Knopf-Ereignisse, Schütteln — der Würfel.

- `loesung.js`: Knopf A zeigt das Herz, Knopf B löscht. Logo nach oben → Pfeil Norden,
  Logo nach unten → Pfeil Süden. Schütteln spielt ein Mittleres C (1 Schlag) und zeigt den
  Totenkopf.
- `loesung-wuerfel.js`: die Team-Challenge, Schütteln zeigt eine Zufallszahl von 1 bis 6.
  Eigenes Programm, weil MakeCode nur ein `wenn geschüttelt` pro Projekt ausführt.

Einfügen: in MakeCode oben auf **JavaScript** umschalten, alles ersetzen, zurück auf **Blöcke**. Noch nicht in MakeCode umgewandelt oder am Gerät gefahren (Stand 05.11.2026).

Nach dem Trockenlauf hier ablegen:

- `loesung.hex`
- `bloecke.png`

und darunter notieren, was das Programm tut und welche Werte darin stecken.
