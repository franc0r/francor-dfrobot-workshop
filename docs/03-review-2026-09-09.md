## Verifiziert — bleibt so
- **Erweiterung `DFRobot_MaqueenPlus_V2` ist korrekt für den V3.** Das Review hatte eine eigene
  V3-Erweiterung vermutet. Der offizielle DFRobot Quick-Start-Guide (wiki.dfrobot.com/mbt0050-aa/docs/23834)
  sagt wörtlich: „Maqueen Plus V3 and Maqueen Plus V2 use the same library … the name of the library
  is still V2, but all the functions of V3 have been integrated."
- Die Erweiterung enthält **deutsche Übersetzungsdateien** → Blöcke erscheinen im deutschen
  Editor auf Deutsch. Exakter Wortlaut trotzdem im Trockenlauf prüfen.
- Chrome/Chromium ≥ 126 stammt aus der micro:bit-Support-Seite (Empfehlung, keine harte Grenze).
- Liniensensor-Werte (weiß ≈ 3800, schwarz ≈ 2700) stammen aus dem DFRobot-Wiki; Richtung wird
  im Trockenlauf gemessen, weil Quiz q3 daran hängt.
