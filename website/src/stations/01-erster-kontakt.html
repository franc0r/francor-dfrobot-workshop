Dein erstes Programm auf echter Hardware

Dein Code wandert über ein Kabel in einen echten Computer – und der macht genau das, was du gesagt hast.

01MakeCode öffnen

  1. Klickt auf den Knopf. MakeCode geht in einem neuen Tab auf, mit einem leeren Projekt.
    Neues Projekt starten →
  2. Links die Block-Kategorien, in der Mitte euer Programm, rechts der Simulator. Blöcke zieht ihr mit gedrückter Maustaste in die Mitte – sie rasten ein wie Puzzleteile.
  3. Zwei Blöcke liegen schon da: beim Start läuft genau einmal, dauerhaft immer wieder, ohne Ende.
So bedient ihr MakeCode

Block holen: aus der Kategorie ziehen oder oben ins Suchfeld tippen.
Block löschen: anklicken, Entf.
Zahl ändern: anklicken, eintippen.

Genau das ist der Unterschied

beim Start zeigt „Hallo“ einmal, dann ist es weg. dauerhaft lässt das Herz blinken, solange Strom da ist. Dieses „immer wieder“ braucht euer Roboter später für jeden Sensor.

03Auf den micro:bit übertragen

  1. micro:bit per USB-Kabel an den Laptop. Den Roboter braucht ihr noch nicht.
  2. In MakeCode auf Herunterladen. Beim ersten Mal fragt der Browser nach dem Gerät → micro:bit koppeln → auswählen → verbinden.
  3. Hinten blinkt eine gelbe LED: Der Code fließt hinüber. Hört sie auf, läuft euer Programm.
Wenn es klemmt

Kein Download möglich? Meist das Kabel: Viele können nur laden. Anderes Kabel probieren.
Der Browser fragt nicht nach dem Gerät? Es muss Chrome oder Edge sein. Notfalls die .hex-Datei auf das Laufwerk MICROBIT ziehen – das geht immer.
